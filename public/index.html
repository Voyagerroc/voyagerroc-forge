What Forge does not do

  • It applies exact edits that you provide. It does not write code with an AI model.
  • Its checks are static. Project tests are not run.
  • It runs locally for one user. Nothing is published or merged.

Run scoped edits

Each before string must match exactly once. Use null for before to create a new file. The runner pins source HEAD and edits a separate copy. Static checks only: conflict markers in edited files, JSON parsing for edited .json files, JavaScript syntax for edited .js/.mjs/.cjs files, and diff whitespace. No AI generation or project tests are run.
