## Product decision

Existing infrastructure is present. Building a new source-control engine solely on the assumption that no framework exists is not justified by these findings. The scaffold therefore tests a narrower product hypothesis: a GitHub-connected workspace that represents agent task intent, workflow plans, change provenance and review across interchangeable future engines.

This is an architectural inference, not verified customer demand or proof of a market gap. The first customer interviews should test whether review visibility and cross-engine coordination solve a real recurring problem beyond existing GitHub/GitLab/agent tools.

GitHub is initially authoritative. No bidirectional mirroring is claimed: the current integration reads repository metadata and ingests signed events. Draft PR publication and native alternative source control are later milestones.

## Research limits

The intended meaning of the spelling "Sicon" remains unconfirmed. The adapter boundary keeps source-control and orchestration choices separate. No public Anthropic Scion interface was identified, and no external compatibility or performance claim has been independently validated by this prototype.
