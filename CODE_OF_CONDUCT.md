# Community code of conduct

Contributors with different backgrounds and levels of experience should be able to work together constructively.

## Expected behavior

- Discuss code, evidence and tradeoffs respectfully.
- Welcome questions and give actionable feedback.
- Credit others and respect privacy.
- Accept that maintainers can decline changes outside project scope.

## Unacceptable behavior

Harassment, threats, discriminatory abuse, sexual harassment, doxxing, publishing private information without permission, spam and deliberate disruption are unacceptable.

## Reporting and enforcement

Report concerns to **voyagerroc@voyagerroctechnologies.com**, including concerns involving a maintainer. The repository maintainer handles reports; share only necessary information. There is no guaranteed response time.

Maintainers may remove abusive content, close disruptive discussions, warn participants or restrict participation. Responses should be proportionate to behavior and impact. This policy covers issues, pull requests and other spaces maintained for this project.
